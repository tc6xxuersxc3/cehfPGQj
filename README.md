# 项目简介

## 核心功能
- 基于YOLOv8的杂草实例分割检测
- 支持图片、视频及摄像头进行检测
- 支持批量检测并查看所有检测结果
- 提供实时显示目标位置、目标总数、置信度等信息
- 支持检测结果保存
- 支持自定义置信度和IOU阈值
- 支持选择显示标签和原图
- 支持选择检测模型

## 适用场景
- 农业杂草识别与检测
- 植物学研究
- 农田自动化管理系统
- 植物分类与计数

## 技术特点
- 采用Pycharm+Anaconda或VSCode+Anaconda开发环境
- 使用Python 3.9、opencv-python、PyQt5、ultralytics、torch1.9等技术栈
- 内置2500张数据集，包含plant和weed两类
- 已训练好的模型，配置成功环境可直接使用
- 提供完整源码、数据集、训练结果及运行教程
